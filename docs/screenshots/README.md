# 界面截图说明

插件安装并重启 `dsh web` 后,计费界面出现在三个位置。建议按下面的清单截图,
放进本目录(如 `stats-bar.png`、`settings-page.png`、`run-card-panel.png`),
并在根 README 的「界面预览」一节引用。

## 截图清单

| 文件 | 位置 | 内容 |
|---|---|---|
| `stats-bar.png` | 输入框正下方的统计条(`conversation.composer.dock`) | `💰 本会话 ¥x.xxxx · 累计 ¥y.yyyy · N 次调用` 实时金额,每 5 秒自动刷新(截图时可见数字随对话跳动) |
| `settings-page.png` | 侧边栏 → 设置 → 「Token 计费」 | 总量卡片(币种/累计成本/调用次数/输入/输出/缓存读)、按会话明细、最近调用明细、单价表、「清零账单」按钮 |
| `run-card-panel.png` | 动态插件时代的 Run 卡面板(仅历史版本可见) | 旧版临时面板(USD/¥),重启后不再出现 |

## 如何截图(macOS)

- 整个窗口:`Cmd + Shift + 4` 后按空格,点击窗口
- 局部区域:`Cmd + Shift + 4`,拖选区域
- 截图默认存到桌面,改名后放入本目录并提交

## 建议

- 统计条截图在**会话进行中**拍摄,能看到本会话金额与累计金额的差异;
- 设置页截图在**切换过会话**后拍摄,按会话明细表会有多行;
- 图片宽度建议 1200px 以内,体积尽量小(PNG/JPG)。
